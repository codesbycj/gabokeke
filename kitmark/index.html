The questions buyers
actually ask us

What do I actually get for the money?

A React codebase covering every screen, with theme tokens you edit in one place. Every page of the dashboard you bought, in desktop and mobile layouts, light and dark themes, and every state wired: empty, loading, error, permission-denied and long-content overflow. Clone it, point it at your API, ship it.

Will these work with my backend?

Yes. Every screen reads through a typed adapter that returns mock data out of the box. You replace the adapter with your own fetch calls, which is one file per view. Nothing is hardcoded inside the components, so swapping the data layer never means editing fifty of them.

Which chart library do you use?

Recharts, wrapped in our own chart components so axes, grid, tooltip and legend all take their styling from your theme tokens. If you would rather use something else, that wrapper is the only thing you rewrite.

Is dark mode a real design or an inversion?

A real design. Both themes were drawn separately, with their own surface values, chart palettes, severity colours and focus rings. Inverting a dashboard is what turns a healthy green KPI into something nobody can read.

Can I use this on client work?

One licence covers unlimited personal and client projects, with no per-seat charge for your team. The only restriction is that you cannot resell the templates themselves as a template.

What about accessibility?

Every screen is keyboard navigable with a visible focus state, tables use real headers and scopes, and colour contrast meets WCAG AA in both themes. Charts carry text alternatives, so the numbers are not locked inside the picture.
